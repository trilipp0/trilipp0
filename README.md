# Filippo Marcatili

> I want to make human-machine interaction seamless.

MSc student in **Human-Centered AI** at [DTU](https://www.dtu.dk), specializing in **Visual Computing**.
Before that, a B.Sc. in Computer, Communications and Electronic Engineering at the University of Trento,
and a semester at NTNU in Trondheim.

I like the place where the digital world and the real one meet: point clouds, Gaussian splats, sensors,
microcontrollers, and the code that glues them together. If something can be automated, I have probably
already thought about automating it twice.
